## Principles

The state reflected in these docs is the one that makes sense for the application currently. Any information here is
subject to change. (Please remember to update the docs when you do make changes!) Architecturally significant changes,
such as rearchitecting the API wrapper, should be documented in an architectural decision record (ADR) in the `/docs/adrs/`
subdirectory. ADRs should follow the template in that directory.
